# Ps1524_tailocin_tradeoffs

This repository contains data, analysis scripts, and figures for the manuscript:

**Population-level trade-offs constrain pathogen evolution: O-antigen variation balances competition and colonization in *Pseudomonas syringae*.**

## Repository structure

- `Ps1524_tailocin_tradeoffs.Rproj` – R project file.
- `data/` – input and intermediate datasets, organized by analysis module.
- `scripts/` – R scripts to reproduce all analyses and figures.
- `figures/` – output figures generated by the scripts.
- `README.md` – this file.

## Workflow

Analyses are organized by manuscript figure order.

### Figure 1

1. **01_tailocin_killing_matrix**  
   - *Data*: tailocin killing matrix assays and phylogeny (Fig. 1A).  
   - *Script*: `scripts/01_tailocin_killing_matrix.R`  
   - *Figure*: `figures/tailocin_killing_matrix.pdf`

2. **02_tailocin_killing_summary**  
   - *Data*: killing assay sensitivity summarized by OBC presence (Fig. 1B).  
   - *Script*: `scripts/02_tailocin_killing_summary.R`  
   - *Figure*: `figures/tailocin_killing_summary.pdf`

3. **03_plant_health_OBC**  
   - *Data*: pixel-based plant health quantification and OBC annotations (Fig. 1C).  
   - *Script*: `scripts/03_plant_health_OBC.R`  
   - *Figure*: `figures/plant_health_OBC.pdf`

### Figure 2

4. **04a_tnseq_plant**  
   - *Data*: in planta TnSeq read counts, ortholog mappings, tailocin TnSeq data.  
   - *Script*: `scripts/04a_tnseq_plant.R`  
   - *Output*: merged gene-level fitness table.

5. **04b_tnseq_scatter**  
   - *Data*: plant vs tailocin fitness from parallel TnSeq experiments (Fig. 2B).  
   - *Script*: `scripts/04b_tnseq_scatter.R`  
   - *Figure*: `figures/tnseq_scatter.pdf`

6. **05_geneplot**  
   - *Data*: O-antigen biosynthesis cluster annotations (Fig. 2C).  
   - *Script*: `scripts/05_geneplot.R`  
   - *Figure*: `figures/geneplot.pdf`

### Figure 3

7. **06_plant_infections_luciferase**  
   - *Data*: luciferase-based infection assays (Fig. 3C).  
   - *Script*: `scripts/06_plant_infections_luciferase.R`  
   - *Figure*: `figures/plant_infections_luciferase.pdf`
